# NutriPlan

Открытый исходный код выпускного проекта — мобильного сервиса планирования питания с рекомендательным модулем и ИИ-коучем.

## Состав репозитория

- `Android/` — приложение для Android на Kotlin.
- `Server/` — REST API на FastAPI, правила рекомендаций, каталог рецептов и тесты.

Приложение позволяет сохранить профиль, сформировать рацион на выбранный период, получить список покупок, вести список продуктов в холодильнике, искать проверенные рецепты и задавать вопросы ИИ-коучу. Параметры профиля используются для расчёта калорийности и ранжирования блюд.

Действующие пароли, пользовательские токены, локальные базы данных, файлы IDE и результаты сборки в исходный код не включены. Установочный APK находится отдельно от репозитория исходников.
