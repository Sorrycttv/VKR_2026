# NutriPlan API

Серверная часть выпускного проекта NutriPlan. API отвечает за регистрацию и вход, хранение профиля, формирование рациона, каталог рецептов, содержимое холодильника и диалог с ИИ-коучем.

## Основные модули

- `app/main.py` — REST-маршруты и связывание компонентов.
- `app/models.py` — таблицы базы данных.
- `app/recommender.py` — формирование многодневного рациона и списка покупок.
- `app/recommendation_rules.py` — расчёт целевой калорийности и порций.
- `app/recommendation_scoring.py` — оценка кандидатов с учётом бюджета и предпочтений.
- `app/recipe_catalog.py` — проверенный встроенный каталог рецептов.
- `app/coach_safety.py` — тематические и безопасностные ограничения ИИ-коуча.
- `app/security.py` — хеширование паролей и работа с JWT.
- `tests/` — модульные тесты вычислительных правил, планирования и ограничений коуча.

## Конфигурация

Настройки читаются из переменных окружения. Файл `.env.example` содержит только безопасные примеры и не включает действующие пароли или ключи.

Для локального запуска через Docker Compose создайте собственный `.env` на основе `.env.example`, затем запустите сервисы `db` и `api`. Модель Ollama задаётся переменными `OLLAMA_BASE_URL` и `OLLAMA_MODEL`.
